Install the downloaded file

In Steam, right-click Deadlock and select Manage > Browse local files.

Click the image to enlarge it.
  1. Close Deadlock completely.
  2. Open Deadlock's local files as shown above, then open game\citadel\addons\.
  3. Move the downloaded pak##_dir.vpk into the addons folder.
  4. Rename it by replacing ## with the next unused two-digit number. For example, if the folder has no existing VPK files, use pak01_dir.vpk. If it already contains pak01_dir.vpk and pak02_dir.vpk, use pak03_dir.vpk.
  5. Launch Deadlock.
